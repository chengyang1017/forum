# Changelog

记录万文社 / Glyphora 的重要功能变化。

本文件只记录具有实际产品意义的功能、架构和数据结构变化。

普通代码整理、小型 UI 调整、格式化等内容由 Git Commit 记录，不需要全部写入这里。

---

## 2026-08-12

### Notes

- 笔记语言数据改为统一使用语言库
- 移除部分页面写死的语言名称和国旗
- NoteModel 新增可选 `languageCode`
- NoteModel 新增可选 `category`
- 笔记分类统一复用论坛帖子分类
- NoteService 支持创建和修改语言、分类
- 笔记编辑器支持修改语言和分类
- 笔记发布帖子时可以复用已有语言和分类
- 缺少发布信息时，在发布阶段补充选择
- 笔记列表支持按语言筛选
- 笔记列表支持按分类筛选
- 语言和分类支持联合筛选
- 重构笔记列表顶部筛选 UI
- 移除大量平铺 ChoiceChip
- 改为点击“语言 / 分类”后弹出选择
- 笔记卡片增加语言和分类信息
- 新建笔记前增加可选配置流程
- 新建笔记时可提前选择语言
- 新建笔记时可提前选择分类
- 新建笔记时可提前选择共享成员
- 只有点击“创建笔记”后才真正写入 Firestore
- 关闭新建配置窗口不会生成空白笔记
- 为“翻译 → 笔记 → 帖子”内容链补充元数据支持
